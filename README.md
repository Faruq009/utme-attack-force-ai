# UTME Attack Force AI Tutor

### Learn. Practice. Attack UTME.

UTME Attack Force AI Tutor is an educational platform designed to help students prepare for the UTME examination.

## Subjects

- 📖 Use of English
- ⚡ Physics
- 🧪 Chemistry
- 📐 Mathematics
- 🧬 Biology

Subject → Class → Topic → Lesson → Practice

The platform is planned to support:

- 📚 Lessons
- 📝 Practice questions
- 🎯 UTME Mock
- 📊 Student progress
- 🔥 Daily Attack
- 🤖 AI Tutor
- 🎤 Voice questions
- 📷 Photo questions
- 💡 Step-by-step explanations
- 📈 Weak-topic detection
- 🔄 Revision mode
